01
AI & Ad Bid Automation
Four systems that keep sponsored ad campaigns priced, scheduled, and honest — running across marketplace and quick-commerce ad platforms with a human always in the loop for anything ambiguous.
MyntraFlipkartAmazon BlinkitInstamartZepto
01 — Bid-Decision Agent
Rules engine + LLM re-price sponsored CPM bids daily from 1/7/15/30-day performance windows. Guardrails: bid floors, escalation ladders, a regression test suite — nothing reaches the ad platform without passing all three.
02 — Budget Scheduler
Pauses, resumes, and re-budgets campaigns by time-of-day and date rules. Rebuilt from fixed time-slots into a one-row-per-window model so marketing can queue unlimited overlapping schedules through a no-code front end — and "resume" correctly means a full campaign rebuild, not a toggle.
03 — Reporting Pipelines
Daily scrapers/API clients pulling campaign, keyword, placement, and city-level data from portals with no public API — replaying captured request signatures and re-reading short-lived tokens live instead of caching them.
04 — Placement Auditor
Browser automation that verifies sponsored placements actually land on the right product page, hit-testing around invisible overlay elements designed to swallow automated clicks silently.
Live in production
02
Warranty & Claims Platform
A serverless pipeline that registers warranties and processes claims for both online and in-store sales — end to end, with no manual data entry.
05 — Registration & Claims
Scheduled cloud functions (minutes for approvals, daily for offline registration, catalogue sync, gap detection) reconcile registration, certificate, and cancellation status across several tables, and guard against double-registration under concurrent runs.
06 — Eligibility Rules Engine
Infers coverage eligibility from cascading signals — name pattern matching, a categorical attribute, price thresholds as a last resort — when no explicit data field exists, with every fallback flagged for retirement once source data improves.
07 — Offline Reconciliation
Joins in-store POS data to the warranty system on verified keys after the obvious ones failed silently — and catches recurring incidents where an upstream customer table arrives late or gets wiped.
Live in production
